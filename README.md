# AI Mandarin Pronunciation Teacher — OpenAI edition

## ภายในชุดไฟล์
- `index.html` เว็บแบบฝึกคำศัพท์ 17 รายการ จากตารางในเอกสารต้นฉบับ
- `netlify/functions/assess.js` Backend ส่งคลิปเสียงไป OpenAI เพื่อรับการประเมินโดยประมาณ
- `netlify.toml` กำหนดตำแหน่งเว็บและ Functions
- `.env.example` ตัวอย่างตัวแปรสภาพแวดล้อม (ห้ามใส่ API Key จริงในไฟล์เว็บหรือ GitHub)

## ติดตั้ง Netlify
1. สร้าง API Key ที่ https://platform.openai.com/api-keys และเปิดใช้งาน billing ตามที่บัญชีต้องการ (ChatGPT Plus ไม่ใช่เครดิต API)
2. แตก ZIP แล้วอัปโหลดโฟลเดอร์โปรเจกต์ไป GitHub repository แบบส่วนตัวหรือสาธารณะ **โดยไม่ใส่ API Key ลงไฟล์**
3. ที่ https://app.netlify.com เลือก Add new project → Import an existing project → GitHub → เลือก repository
4. Build command เว้นว่าง; Publish directory เป็น `.`; Functions directory ใช้ `netlify/functions` จาก netlify.toml
5. ไปที่ Site configuration → Environment variables → Add variable: `OPENAI_API_KEY` = API Key จริง; scope ต้องครอบคลุม Functions; ตัวเลือก `OPENAI_AUDIO_MODEL` = `gpt-4o-audio-preview` (ขึ้นกับสิทธิ์และรุ่นที่ API รองรับ)
6. Deploy หรือ Trigger deploy ใหม่หลังตั้งค่า แล้วเปิด URL HTTPS ของ Netlify
7. ใส่ข้อมูลนักศึกษา → เลือกคำ → ฟังตัวอย่าง → บันทึก → หยุด → กด AI ประเมิน → ส่งออก CSV

## หมายเหตุสำคัญด้านความแม่นยำ
- ใช้ audio-capable model รับคลิปเสียงจริงผ่าน API แต่ผลด้านพยัญชนะ สระ และวรรณยุกต์เป็น **การตัดสินเชิงคุณภาพโดยโมเดล** ไม่ใช่คะแนนสัทศาสตร์จากเครื่องมือเฉพาะทางที่ผ่านการทดสอบความเที่ยงตรง
- โมเดลอาจประเมินวรรณยุกต์ผิด หรือให้ผลไม่สม่ำเสมอ โดยเฉพาะเสียงสั้น เสียงเบา และการเปลี่ยนเสียงวรรณยุกต์ในคำต่อเนื่อง
- ถ้าฟังไม่ชัด AI สามารถส่ง `null` สำหรับคะแนนด้านนั้น และระบบจะไม่สรุปคะแนนเต็ม 20 จนกว่าจะได้ผลครบ
- **คะแนนใช้เพื่อฝึกและรับ feedback เท่านั้น** ควรมีผู้สอนยืนยันก่อนบันทึกเป็นคะแนนทางการ
- ตารางในเอกสารมี 17 รายการ แต่หัวข้อระบุ 20 ตัวอักษร/20 คะแนน จึงใช้คะแนนดิบ 51 และแปลงเป็น 20 ตามสูตรที่ระบุในหน้าเว็บ ไม่ได้เพิ่มคำศัพท์ที่ไม่มีในตาราง
- รายการ 你好 และคำเสียงเบา เช่น 你们、早上 ต้องพิจารณาการออกเสียงในบริบท

## ความเป็นส่วนตัวและค่าใช้จ่าย
- เสียงถูกส่งจากเบราว์เซอร์ไปยัง Netlify Function และ OpenAI API เพื่อประมวลผล โปรดแจ้งนักศึกษาและขอความยินยอมตามนโยบายของสถาบันก่อนใช้งาน
- โค้ดตัวอย่างนี้ไม่เก็บไฟล์เสียงหรือผลไว้ในฐานข้อมูล; ข้อมูลในหน้าเว็บจะหายเมื่อรีเฟรช (ควรส่งออก CSV)
- ทุกครั้งที่ประเมินมีค่าใช้จ่าย API ตามโมเดลและปริมาณเสียง ดู https://platform.openai.com/pricing/
- ยังไม่มี login, rate limiting, captcha หรือการจำกัด quota ต่อผู้ใช้ **ควรเพิ่มการป้องกันเหล่านี้ก่อนเผยแพร่ให้คนจำนวนมาก** เพื่อป้องกันการใช้ API โดยไม่ได้รับอนุญาต
- ไม่ควรอัปโหลด API Key ไป GitHub หรือฝังใน HTML

## ทดสอบ
- ทดสอบโครงสร้างไฟล์และไวยากรณ์ JavaScript ได้โดย `node --check netlify/functions/assess.js`
- ต้อง deploy และมี API Key ที่ใช้งานได้จึงจะทดสอบการประเมินจริงได้; หาก API แจ้งว่าโมเดลไม่รองรับ audio input หรือ format ให้ตรวจสอบรุ่นและเอกสาร API ปัจจุบัน
- MediaRecorder ของบางเบราว์เซอร์อาจส่งไฟล์ `audio/mp4` ซึ่ง API บางรุ่นอาจไม่รับผ่าน `input_audio`; ควรทดสอบบน Chrome/Edge ก่อนใช้งานจริง
